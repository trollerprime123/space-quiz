# Orbit: Space Exploration Quiz

Orbit is a responsive, single-page space quiz with ten questions, animated answer feedback, a progress bar, score tracking, a personal best, missed-answer explanations, and shuffled questions on replay. It supports light and dark color schemes and reduced-motion preferences.

## Run locally

No installation, build step, or server is required. Open `index.html` directly in a modern web browser.

## Deployment

GitHub Actions publishes the static site to GitHub Pages whenever changes are pushed to `main`. The workflow can also be started manually from the Actions tab.
